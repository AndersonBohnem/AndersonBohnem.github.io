# Portfólio Pessoal

Portfólio profissional de Anderson Bohnemberger, desenvolvido em HTML e CSS, com foco em apresentar experiência em automação de testes, qualidade de software e transição para desenvolvimento backend.

## Objetivo

Este projeto foi criado para servir como vitrine profissional, reunindo:

- apresentação pessoal
- experiência profissional
- stack técnica
- projetos em destaque
- formação
- formas de contato
- currículo em PDF

## Tecnologias

- HTML5
- CSS3

## Estrutura do projeto

```text
.
|-- assets/
|   |-- fotoCapa.ico
|   `-- main.jpeg
|-- curriculo-anderson-bohnemberger.pdf
|-- index.html
|-- README.md
`-- style.css
```

## Seções da página

- Início
- Sobre
- Experiência
- Stack
- Projetos
- Formação
- Contato

## Como visualizar

Basta abrir o arquivo `index.html` no navegador.

## Personalização

Os principais pontos de manutenção do projeto são:

- conteúdo da página em `index.html`
- identidade visual e responsividade em `style.css`
- foto principal em `assets/main.jpeg`
- currículo em `curriculo-anderson-bohnemberger.pdf`

## Observações

- o projeto é estático e não utiliza JavaScript
- o menu superior foi pensado para navegação por âncoras na mesma página
- o currículo é aberto em nova guia a partir dos links da interface
